# 二叉树遍历

> 一句话结论：前中后序是 DFS（递归或显式栈），层序是 BFS（队列）；迭代写法的关键是「入栈顺序」和「访问时机」，而不是死记模板。

## 为什么考 / 怎么考

遍历是二叉树一切题目的基础。面试官通常会让你先写递归，再要求改成迭代，最后追问后序和层序。典型追问链：

1. 前中后序的递归顺序？
2. 不用递归怎么写？
3. 后序迭代为什么比前序难？
4. 层序遍历怎么按层分组？
5. 空间复杂度是多少？

## 思路

### 前序 / 中序 / 后序

- 前序：根 → 左 → 右；
- 中序：左 → 根 → 右；
- 后序：左 → 右 → 根。

递归写法只是把「访问根」放在不同位置。

### 迭代写法

- **前序**：栈里先压右孩子、再压左孩子，弹出时就是「根左右」；
- **中序**：一路向左入栈，弹出节点时访问，然后转向右子树；
- **后序**：按「根右左」做前序变体，最后把结果反转，得到「左右根」；也可以用双栈或记录 last visited。

### 层序

用队列：每轮先记录当前层的节点数 `n`，只弹出 `n` 个节点，就能按层分组。

### 复杂度

- 时间：每个节点访问一次，O(n)；
- 空间：递归/栈 O(h)，h 为树高，最坏 O(n)；层序队列最坏 O(n)（完全二叉树最后一层）。

## 代码示例

递归三种遍历：

```cpp
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

void preorder(TreeNode* r, std::vector<int>& out) {
    if (!r) return;
    out.push_back(r->val);
    preorder(r->left, out);
    preorder(r->right, out);
}

void inorder(TreeNode* r, std::vector<int>& out) {
    if (!r) return;
    inorder(r->left, out);
    out.push_back(r->val);
    inorder(r->right, out);
}

void postorder(TreeNode* r, std::vector<int>& out) {
    if (!r) return;
    postorder(r->left, out);
    postorder(r->right, out);
    out.push_back(r->val);
}
```

前序迭代：

```cpp
#include <stack>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

std::vector<int> preorderIter(TreeNode* root) {
    std::vector<int> out;
    std::stack<TreeNode*> st;
    if (root) st.push(root);

    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();
        out.push_back(node->val);

        if (node->right) st.push(node->right);   // 先右后左
        if (node->left) st.push(node->left);
    }
    return out;
}
```

中序迭代：

```cpp
#include <stack>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

std::vector<int> inorderIter(TreeNode* root) {
    std::vector<int> out;
    std::stack<TreeNode*> st;
    TreeNode* cur = root;

    while (cur || !st.empty()) {
        while (cur) {            // 一路向左
            st.push(cur);
            cur = cur->left;
        }
        cur = st.top();
        st.pop();
        out.push_back(cur->val); // 访问根
        cur = cur->right;        // 转向右子树
    }
    return out;
}
```

后序迭代（前序变体 + 反转）：

```cpp
#include <algorithm>
#include <stack>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

std::vector<int> postorderIter(TreeNode* root) {
    std::vector<int> out;
    std::stack<TreeNode*> st;
    if (root) st.push(root);

    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();
        out.push_back(node->val);

        if (node->left) st.push(node->left);   // 先左后右
        if (node->right) st.push(node->right);
    }
    std::reverse(out.begin(), out.end());      // 根右左 → 左右根
    return out;
}
```

层序遍历：

```cpp
#include <queue>
#include <utility>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

std::vector<std::vector<int>> levelOrder(TreeNode* root) {
    std::vector<std::vector<int>> out;
    if (!root) return out;

    std::queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int n = static_cast<int>(q.size());
        std::vector<int> level;
        for (int i = 0; i < n; ++i) {
            TreeNode* node = q.front();
            q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        out.push_back(std::move(level));
    }
    return out;
}
```

## 高频追问

**Q1：递归和迭代怎么选？**
A：递归写法短、可读性好，但深度大时可能爆栈；迭代用显式栈，空间可控，面试常要求两种都会。

**Q2：中序迭代为什么能按顺序访问？**
A：先把整条左链入栈，栈顶就是最左节点；访问后转向它的右子树，再重复「一路向左」，天然得到「左根右」。

**Q3：后序迭代为什么特殊？**
A：后序要求左右都访问完才访问根，直接迭代需要记录上一个访问节点。更简单的做法是按「根右左」遍历再反转，得到「左右根」。

**Q4：层序怎么按层分组？**
A：每轮先记下队列当前大小 `n`，只处理 `n` 个节点，这 `n` 个正好是同一层。

**Q5：遍历的空间复杂度？**
A：递归/迭代栈 O(h)，最坏（链状树）O(n)；层序队列最坏 O(n)（完全二叉树最后一层）。

**Q6：Morris 遍历是什么？**
A：利用叶子节点的空右指针建立临时线索，做到 O(1) 额外空间的中序遍历；遍历后要恢复指针，代码较复杂，面试中能说出思想即可。

**Q7：BST 的中序遍历有什么性质？**
A：二叉搜索树的中序遍历是严格递增序列，常用于验证 BST、找第 k 小、找中位数。

## 易错点与加分点

- 前序迭代先压左再压右，导致顺序变成「根右左」。
- 中序迭代忘记把 `cur` 转到右子树，死循环。
- 层序不在每轮固定 `n`，无法按层分组。
- 递归不判空，空指针访问。
- 能说出后序「根右左再反转」的技巧，以及 Morris 的 O(1) 空间思想。
