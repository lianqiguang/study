# 二分查找

> 一句话结论：二分查找在有序数据上每次砍掉一半，复杂度 O(log n)；写对的关键是固定区间不变量（推荐半开区间 `[lo, hi)`），以及用 `lo + (hi - lo) / 2` 防止溢出。

## 为什么考 / 怎么考

二分是「一看就会、一写就错」的代表，面试官主要看边界处理。典型追问链：

1. `mid` 为什么写成 `lo + (hi - lo) / 2`？
2. `lower_bound` 和 `upper_bound` 有什么区别？
3. 为什么推荐半开区间？
4. 旋转数组怎么二分？
5. 什么是「二分答案」？

## 思路

### 1. 前提与不变量

二分要求数据**有序**（或满足单调性）。推荐使用半开区间 `[lo, hi)`：

- 初始 `lo = 0, hi = n`；
- 循环条件 `lo < hi`；
- 每次保证答案在 `[lo, hi)` 内；
- 结束时 `lo == hi` 就是答案位置。

`mid = lo + (hi - lo) / 2` 等价于 `(lo + hi) / 2`，但避免了 `lo + hi` 溢出。

### 2. lower_bound 与 upper_bound

- `lower_bound(x)`：第一个 **大于等于** `x` 的位置；
- `upper_bound(x)`：第一个 **大于** `x` 的位置；
- 两者相减就是 `x` 的出现次数。

区别只在比较条件：`a[mid] < x` 时 `lo = mid + 1`，否则 `hi = mid`，得到 lower_bound；把 `<` 换成 `<=`，得到 upper_bound。

### 3. 查找精确值

先 `lower_bound` 找到第一个 ≥ 目标的位置，再检查该位置是否等于目标。不要直接用 `a[mid] == target` 就返回，否则面对重复元素时得到的不一定是第一个。

### 4. 旋转数组

有序数组被旋转后（如 `[4,5,6,7,0,1,2]`），每次至少有一半是有序的：

- 若 `a[lo] <= a[mid]`，左半有序：目标在 `[a[lo], a[mid])` 内就收缩到左边，否则去右边；
- 否则右半有序：目标在 `(a[mid], a[hi]]` 内就去右边，否则去左边。

以下写法假设元素**互不相同**（LeetCode 33）。有重复元素时（LeetCode 81），`a[lo] == a[mid]` 无法判断哪一半有序，需要先 `++lo` 缩小区间，否则会漏掉正确答案。

### 5. 二分答案

当「判定某个值是否可行」具有单调性时，可以对答案空间二分：

- 定义 `feasible(x)`：x 越大越容易满足（或越小越容易）；
- 二分最小的可行值或最大的可行值；
- 例：运载能力、分割数组的最大值、最小化最大值。

## 代码示例

`lower_bound`：

```cpp
#include <vector>

int lowerBound(const std::vector<int>& a, int target) {
    int lo = 0, hi = static_cast<int>(a.size());
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;   // 第一个 >= target 的位置
}
```

`upper_bound`：

```cpp
#include <vector>

int upperBound(const std::vector<int>& a, int target) {
    int lo = 0, hi = static_cast<int>(a.size());
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo;   // 第一个 > target 的位置
}
```

统计出现次数：

```cpp
#include <vector>

int countOccurrences(const std::vector<int>& a, int target) {
    int n = static_cast<int>(a.size());

    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    int lower = lo;

    lo = 0; hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1;
        else hi = mid;
    }
    return lo - lower;
}
```

旋转数组查找：

```cpp
#include <vector>

int searchRotated(const std::vector<int>& a, int target) {
    int lo = 0, hi = static_cast<int>(a.size()) - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;

        if (a[lo] == a[mid]) {                       // 有重复值：无法判断哪半有序
            ++lo;
            continue;
        }
        if (a[lo] <= a[mid]) {                       // 左半有序
            if (a[lo] <= target && target < a[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                                     // 右半有序
            if (a[mid] < target && target <= a[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}
```

二分答案（最小运载能力）：

```cpp
#include <algorithm>
#include <vector>

bool canShip(const std::vector<int>& w, int days, int cap) {
    int need = 1, used = 0;
    for (int x : w) {
        if (used + x > cap) {
            ++need;
            used = 0;
        }
        used += x;
    }
    return need <= days;
}

int shipWithinDays(const std::vector<int>& w, int days) {
    int lo = 0, hi = 0;
    for (int x : w) {
        lo = std::max(lo, x);   // 至少能装下最重的一件
        hi += x;                // 最多一次装完
    }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canShip(w, days, mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

## 高频追问

**Q1：`mid` 为什么写成 `lo + (hi - lo) / 2`？**
A：避免 `lo + hi` 在接近 `INT_MAX` 时溢出；两者数学上相等，但前者更安全。

**Q2：`lower_bound` 和 `upper_bound` 有什么区别？**
A：`lower_bound` 返回第一个 ≥ x 的位置，`upper_bound` 返回第一个 > x 的位置；相减得到 x 的出现次数。

**Q3：为什么推荐半开区间 `[lo, hi)`？**
A：不变量统一（答案始终在 `[lo, hi)` 内），`hi` 可以等于 `n`，不需要为「找不到」单独处理 `n - 1` 的边界；循环结束时 `lo == hi`。

**Q4：旋转数组二分的核心是什么？**
A：每次比较 `a[lo]` 与 `a[mid]`，判断哪一半有序，再根据目标是否落在有序区间内收缩。

**Q5：二分答案需要什么条件？**
A：判定函数具有单调性——随着答案增大（或减小），可行性从「不满足」变成「满足」且不再回头。

**Q6：二分查找的时间复杂度？**
A：每次区间减半，O(log n)；如果每次比较是 O(1)。对链表等不支持随机访问的结构，二分不划算。

**Q7：`std::lower_bound` 怎么用？**
A：`std::lower_bound(a.begin(), a.end(), x)` 返回第一个 ≥ x 的迭代器；要求区间按 `<` 有序（或传入自定义比较）。

## 易错点与加分点

- `while (lo <= hi)` 与 `[lo, hi)` 混用，导致死循环或漏元素。
- 收缩边界时写成 `lo = mid`，区间不再缩小。
- 用 `a[mid] == target` 直接返回，重复元素时不是第一个。
- 忘记检查 `lower_bound` 的结果是否越界。
- 能说出半开区间的不变量，以及二分答案的单调性前提。
