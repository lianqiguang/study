# 链表高频题

> 一句话结论：链表题的核心套路是「虚拟头节点 + 双指针 + 画图改指针」；反转、找中点、判环、合并、删倒数第 n 个都能用 O(1) 额外空间写完。

## 为什么考 / 怎么考

链表题考的是指针操作的严谨性：边界、空指针、断链顺序。面试官通常先让你手写反转或合并，再追问环的入口、偶数个节点的中点、能不能一趟删倒数第 n 个。典型追问链：

1. 反转链表怎么保证不断链？
2. 快慢指针为什么能找到中点？
3. 怎么判断有环？入口怎么找？
4. 删除倒数第 n 个为什么要用哨兵？
5. 两个链表相交怎么求交点？

## 套路

- **虚拟头节点（dummy）**：避免「删除头节点」单独分支，最后返回 `dummy.next`。
- **快慢指针**：找中点、判环、找倒数第 n 个。
- **改指针前先保存 next**：反转时顺序是 `next = cur->next; cur->next = prev; prev = cur; cur = next;`。
- **画图**：链表题不画图，边界几乎必错。

## 代码示例

反转链表（迭代 + 递归）：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* next = head->next;   // 先保存
        head->next = prev;             // 再反转
        prev = head;
        head = next;
    }
    return prev;
}

ListNode* reverseListRec(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseListRec(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}
```

找中点（偶数个返回第二个中点）：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

判环与找入口（Floyd）：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            ListNode* p = head;
            while (p != slow) {   // 从头和相遇点同速走，交点即入口
                p = p->next;
                slow = slow->next;
            }
            return p;
        }
    }
    return nullptr;
}
```

合并两个有序链表：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) {   // <= 保证稳定
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}
```

删除倒数第 n 个：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0);
    dummy.next = head;

    ListNode* fast = &dummy;
    ListNode* slow = &dummy;

    for (int i = 0; i <= n; ++i) {   // fast 先走 n+1 步
        fast = fast->next;
    }
    while (fast) {
        fast = fast->next;
        slow = slow->next;
    }
    slow->next = slow->next->next;
    return dummy.next;
}
```

## 高频追问

**Q1：反转链表为什么不会断链？**
A：每一步先用 `next` 保存后继，再改 `head->next`，最后把 `prev`/`head` 前移。顺序反了就会丢失后半段。

**Q2：快慢指针为什么能找到中点？**
A：快指针每次走两步，慢指针走一步；快指针到末尾时，慢指针正好走了一半。偶数个节点时，返回的是第二个中点。

**Q3：Floyd 判环的入口为什么这样找？**
A：设头到入口距离 a，入口到相遇点距离 b，环长 c。相遇时慢指针走 a+b，快指针走 a+b+kc，且快是慢的两倍，可得 a = c - b（模 c）。所以从头和相遇点同速走会在入口相遇。

**Q4：删除倒数第 n 个为什么要用哨兵？**
A：如果删的是头节点，需要改头指针；用 dummy 统一成「删除某个节点的后继」，不需要单独分支。快指针先走 n+1 步，之后快慢同速，慢指针停在待删节点的前一个。

**Q5：两个链表相交怎么求交点？**
A：双指针分别走完自己的链表后跳到对方头部，两轮后走过的总长度相同，会在交点相遇；无交点则同时为空。

**Q6：反转链表递归写法的空间复杂度？**
A：O(n) 递归栈；迭代写法 O(1)。

**Q7：合并两个有序链表怎么保持稳定？**
A：相等时优先取第一个链表的节点（`<=`），相等元素的相对顺序不变。

## 易错点与加分点

- 反转时先改指针再保存后继，导致断链。
- 快慢指针循环条件只写 `fast`，空指针访问 `fast->next`。
- 删除倒数第 n 个时快指针少走一步，删错节点。
- 合并时忘记接上剩余部分。
- 能说出 Floyd 入口的推导，以及 dummy 统一边界的作用。
