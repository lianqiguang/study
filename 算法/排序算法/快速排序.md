# 快速排序

> 一句话结论：快排选一个基准把数组分成「小于 / 大于」两段再递归，平均 O(n log n)、原地但不稳定；最坏 O(n²) 出现在每次分区极不平衡时，随机基准和三路分区可以缓解。

## 为什么考 / 怎么考

快排是手写题里的常客，面试官会看你能不能写对 partition、说清最坏情况、以及知道怎么优化。典型追问链：

1. 快排的平均和最坏复杂度？
2. Lomuto 和 Hoare 分区有什么区别？
3. 为什么随机基准能降低最坏情况的概率？
4. 大量重复元素时怎么优化？
5. `std::sort` 是快排吗？

## 思路

1. 选一个基准 `pivot`；
2. 分区：把小于基准的放左边、大于的放右边，返回基准最终位置；
3. 递归处理左右两段。

**Lomuto 分区**：基准放到末尾，用 `i` 标记「小于区」的边界，遍历时把小于基准的元素换到前面，最后把基准换到 `i`。写法简单，但交换次数偏多，重复元素多时退化。

**Hoare 分区**：左右指针向中间靠拢，交换逆序对。交换次数少，但边界更容易写错。

**稳定性**：快排不稳定，分区过程中的交换会打乱相等元素的相对顺序。

### 复杂度

- 平均：每次大致平分，递归深度 O(log n)，每层 O(n)，总计 O(n log n)；
- 最坏：每次只分出一个元素（例如已排序数组 + 取首元素为基准），递归深度 O(n)，总计 O(n²)；
- 空间：递归栈 O(log n)（平均），最坏 O(n)；原地排序，不需要额外数组。

### 优化手段

- **随机基准**：把最坏情况的概率降到极低；
- **三数取中**：取首、中、尾的中位数做基准；
- **三路分区**（荷兰国旗）：分成 `< pivot`、`== pivot`、`> pivot` 三段，重复元素多时接近线性；
- **小区间用插入排序**：元素少时插入排序更快；
- **限制递归深度**：深度超过 `2 * log2(n)` 时改用堆排序（introsort 的做法）。

`std::sort` 通常实现为 introsort：快排 + 堆排兜底 + 小区间插入排序，最坏也是 O(n log n)。

## 代码示例

Lomuto 分区版本：

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int partition(std::vector<int>& a, int lo, int hi) {
    int pivot = a[hi];
    int i = lo;
    for (int j = lo; j < hi; ++j) {
        if (a[j] < pivot) {
            std::swap(a[i], a[j]);
            ++i;
        }
    }
    std::swap(a[i], a[hi]);
    return i;
}

void quickSort(std::vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}

int main() {
    std::vector<int> v{5, 2, 9, 1, 5, 6};
    quickSort(v, 0, static_cast<int>(v.size()) - 1);
    for (int x : v) std::cout << x << ' ';
}
```

随机基准版本：

```cpp
#include <random>
#include <vector>

void quickSort(std::vector<int>& a, int lo, int hi, std::mt19937& rng) {
    if (lo >= hi) return;

    std::uniform_int_distribution<int> dist(lo, hi);
    std::swap(a[lo], a[dist(rng)]);   // 随机基准

    int pivot = a[lo];
    int i = lo, j = hi;
    while (i < j) {
        while (i < j && a[j] >= pivot) --j;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) ++i;
        a[j] = a[i];
    }
    a[i] = pivot;

    quickSort(a, lo, i - 1, rng);
    quickSort(a, i + 1, hi, rng);
}
```

三路分区（重复元素多时）：

```cpp
#include <algorithm>
#include <vector>

void quickSort3Way(std::vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;

    int pivot = a[lo];
    int lt = lo, i = lo + 1, gt = hi;
    while (i <= gt) {
        if (a[i] < pivot) {
            std::swap(a[lt++], a[i++]);
        } else if (a[i] > pivot) {
            std::swap(a[i], a[gt--]);
        } else {
            ++i;
        }
    }

    quickSort3Way(a, lo, lt - 1);
    quickSort3Way(a, gt + 1, hi);
}
```

## 高频追问

**Q1：快排为什么最坏是 O(n²)？**
A：每次分区只把基准放到一端，递归深度变成 O(n)，每层仍要 O(n)，总计 O(n²)。已排序数组取首/尾元素做基准就是典型例子。

**Q2：Lomuto 和 Hoare 分区的区别？**
A：Lomuto 用单指针把小于基准的元素换到前面，最后交换基准，写法简单但交换多；Hoare 用左右双指针交换逆序对，交换少但边界条件更绕。

**Q3：随机基准为什么有用？**
A：让「每次分区都极不平衡」不再由输入顺序决定，而是变成小概率事件；对任意固定输入，期望复杂度仍是 O(n log n)。

**Q4：大量重复元素时怎么办？**
A：用三路分区，把等于基准的元素集中到中间，只递归两侧；重复元素多时复杂度接近 O(n)。

**Q5：快排稳定吗？**
A：不稳定。分区交换会改变相等元素的相对顺序；需要稳定排序时用归并排序。

**Q6：`std::sort` 是快排吗？**
A：通常是 introsort：快排为主，递归过深时切换堆排序，小区间用插入排序，最坏 O(n log n)。

**Q7：递归深度怎么控制？**
A：优先递归较小的一段、较大的一段用循环（尾递归优化），或显式栈；也可以限制深度，超过阈值改用堆排序。

## 易错点与加分点

- partition 的边界写错，导致死循环或漏元素。
- 忘记处理 `lo >= hi`，空区间越界。
- 以为快排稳定，或以为平均 O(n log n) 就没有 O(n²) 风险。
- 只写 Lomuto，不知道重复元素会退化。
- 能说出 introsort 的三段式设计，是明显的加分项。
