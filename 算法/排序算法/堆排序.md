# 堆排序

> 一句话结论：堆排序用数组表示完全二叉树，先自底向上建堆（O(n)），再反复把堆顶换到末尾并下沉，整体 O(n log n)、原地、不稳定。

## 为什么考 / 怎么考

堆是「排序 + TopK + 优先队列」的共同基础，面试官常从「建堆为什么是 O(n)」和「TopK 用什么堆」切入。典型追问链：

1. 堆的数组下标关系是什么？
2. 建堆为什么是 O(n) 而不是 O(n log n)？
3. 堆排序的复杂度？稳定吗？
4. 求 TopK 用大顶堆还是小顶堆？
5. 堆排序和快排怎么选？

## 思路

### 1. 数组表示完全二叉树

0 基下标：

- 父节点：`(i - 1) / 2`
- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`

大顶堆满足：每个节点的值都大于等于它的孩子。

### 2. 建堆

从最后一个非叶子节点 `n / 2 - 1` 开始，依次向前对每个节点做下沉（sift-down）。叶子节点天然是堆，不需要处理。

建堆的总代价是 O(n)：大部分节点在底层，下沉高度小；可以用等比级数证明，而不是「n 个节点 × log n」。

### 3. 排序

1. 建好大顶堆后，堆顶是最大值；
2. 把堆顶与末尾元素交换，最大值归位；
3. 堆大小减一，对新的堆顶下沉；
4. 重复直到堆大小为 1。

每次下沉 O(log n)，共 n 次，总时间 O(n log n)。

### 4. 复杂度与性质

- 时间：建堆 O(n) + 排序 O(n log n) = O(n log n)，最好/平均/最坏都一样；
- 空间：O(1)，原地排序；
- 稳定性：不稳定，交换会打乱相等元素的相对顺序。

### 5. TopK

求最大的 k 个元素，维护一个大小为 k 的**小顶堆**：

- 堆里始终保存当前最大的 k 个；
- 新元素比堆顶大就替换堆顶并下沉；
- 时间 O(n log k)，空间 O(k)。

求第 k 大也用同样的小顶堆，最后堆顶就是答案。

## 代码示例

```cpp
#include <iostream>
#include <vector>

void siftDown(std::vector<int>& a, int n, int i) {
    while (true) {
        int largest = i;
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest == i) break;
        std::swap(a[i], a[largest]);
        i = largest;
    }
}

void heapSort(std::vector<int>& a) {
    int n = static_cast<int>(a.size());

    for (int i = n / 2 - 1; i >= 0; --i) {   // 建堆 O(n)
        siftDown(a, n, i);
    }
    for (int i = n - 1; i > 0; --i) {        // 排序 O(n log n)
        std::swap(a[0], a[i]);
        siftDown(a, i, 0);
    }
}

int main() {
    std::vector<int> v{5, 2, 9, 1, 5, 6};
    heapSort(v);
    for (int x : v) std::cout << x << ' ';
}
```

TopK（小顶堆）：

```cpp
#include <functional>
#include <queue>
#include <vector>

std::vector<int> topK(const std::vector<int>& nums, int k) {
    std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;
    for (int x : nums) {
        minHeap.push(x);
        if (static_cast<int>(minHeap.size()) > k) {
            minHeap.pop();
        }
    }

    std::vector<int> result;
    while (!minHeap.empty()) {
        result.push_back(minHeap.top());
        minHeap.pop();
    }
    return result;
}
```

标准库默认大顶堆：

```cpp
#include <queue>

int main() {
    std::priority_queue<int> pq;   // 默认大顶堆
    pq.push(3);
    pq.push(1);
    pq.push(2);
    int top = pq.top();            // 3
    (void)top;
}
```

## 高频追问

**Q1：建堆为什么是 O(n)？**
A：从最后一个非叶子节点向前下沉，第 h 层节点数约 n/2^h、下沉高度 h，总代价 Σ(n/2^h · h) = O(n)。底层节点多但下沉少，顶层节点少但下沉多。

**Q2：堆排序稳定吗？**
A：不稳定。堆顶与末尾交换会把远处元素直接搬过来，相等元素的相对顺序无法保证。

**Q3：TopK 用大顶堆还是小顶堆？**
A：求最大的 k 个用小顶堆（堆顶是当前 k 个里最小的，方便淘汰）；求最小的 k 个用大顶堆。

**Q4：堆排序和快排怎么选？**
A：需要最坏 O(n log n) 且在乎空间时用堆排序；平均性能和缓存友好性通常快排更好。`std::sort` 的 introsort 会在递归过深时切到堆排序。

**Q5：`priority_queue` 和堆是什么关系？**
A：`priority_queue` 是容器适配器，默认用 `vector` + 堆算法实现，默认大顶堆；可以指定 `greater<T>` 变成小顶堆。

**Q6：如何求第 k 大元素？**
A：维护大小为 k 的小顶堆，遍历完数组后堆顶就是第 k 大；时间 O(n log k)，空间 O(k)。也可以用快速选择做到平均 O(n)。

**Q7：堆的插入和删除复杂度？**
A：插入到末尾后上浮，O(log n)；删除堆顶时把末尾移到堆顶再下沉，O(log n)。

## 易错点与加分点

- 下标关系写成 1 基的 `2i`/`2i+1`，数组却从 0 开始。
- 建堆时从 `n/2` 开始或从前往后，导致结果不是堆。
- 下沉时只和左孩子比较，忘记右孩子。
- 以为堆排序稳定。
- 能说出建堆 O(n) 的级数证明，以及 TopK 用小顶堆的理由。
