# 归并排序

> 一句话结论：归并排序把数组对半拆开、分别排好再合并，任何情况下都是 O(n log n)，并且稳定；代价是需要 O(n) 的额外空间。

## 为什么考 / 怎么考

归并排序是「分治 + 稳定排序」的代表，也常被用来考逆序对、链表排序和外部排序。典型追问链：

1. 归并排序的复杂度？为什么任何情况都是 O(n log n)？
2. 它为什么稳定？
3. 能不能做到 O(1) 额外空间？
4. 链表排序为什么更适合归并？
5. 怎么用归并求逆序对？

## 思路

1. 把区间 `[lo, hi]` 分成两半；
2. 递归排序左右两半；
3. 合并两个有序区间：双指针比较，较小者先放入缓冲区。

合并时用 `a[i] <= a[j]` 取左边元素，保证相等元素的相对顺序不变，这就是稳定性的来源。

### 复杂度

- 时间：递归深度 O(log n)，每层合并 O(n)，最好/平均/最坏都是 O(n log n)；
- 空间：数组归并需要 O(n) 缓冲区；链表归并只需要指针操作，额外空间 O(log n)（递归栈）或 O(1)（迭代版）；
- 稳定性：稳定。

## 代码示例

数组的归并排序：

```cpp
#include <iostream>
#include <vector>

void merge(std::vector<int>& a, int lo, int mid, int hi, std::vector<int>& buf) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (a[i] <= a[j]) buf[k++] = a[i++];   // <= 保证稳定
        else buf[k++] = a[j++];
    }
    while (i <= mid) buf[k++] = a[i++];
    while (j <= hi) buf[k++] = a[j++];
    for (int t = lo; t <= hi; ++t) a[t] = buf[t];
}

void mergeSort(std::vector<int>& a, int lo, int hi, std::vector<int>& buf) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, lo, mid, buf);
    mergeSort(a, mid + 1, hi, buf);
    merge(a, lo, mid, hi, buf);
}

int main() {
    std::vector<int> v{5, 2, 9, 1, 5, 6};
    std::vector<int> buf(v.size());
    mergeSort(v, 0, static_cast<int>(v.size()) - 1, buf);
    for (int x : v) std::cout << x << ' ';
}
```

用归并求逆序对：当右半元素先被取出时，左半剩余元素都大于它，贡献 `mid - i + 1` 个逆序对：

```cpp
#include <vector>

long long mergeCount(std::vector<int>& a, int lo, int mid, int hi, std::vector<int>& buf) {
    long long inv = 0;
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (a[i] <= a[j]) {
            buf[k++] = a[i++];
        } else {
            inv += mid - i + 1;
            buf[k++] = a[j++];
        }
    }
    while (i <= mid) buf[k++] = a[i++];
    while (j <= hi) buf[k++] = a[j++];
    for (int t = lo; t <= hi; ++t) a[t] = buf[t];
    return inv;
}

long long countInversions(std::vector<int>& a, int lo, int hi, std::vector<int>& buf) {
    if (lo >= hi) return 0;
    int mid = lo + (hi - lo) / 2;
    long long inv = countInversions(a, lo, mid, buf)
                  + countInversions(a, mid + 1, hi, buf);
    return inv + mergeCount(a, lo, mid, hi, buf);
}
```

链表归并排序（快慢指针找中点）：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

ListNode* merge(ListNode* a, ListNode* b) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else                  { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}

ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;

    ListNode* slow = head;
    ListNode* fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }

    ListNode* mid = slow->next;
    slow->next = nullptr;
    return merge(sortList(head), sortList(mid));
}
```

## 高频追问

**Q1：为什么归并排序任何情况都是 O(n log n)？**
A：递归树固定为 O(log n) 层，每层合并总量 O(n)，与输入顺序无关；不存在快排那种极端不平衡的退化。

**Q2：归并排序为什么稳定？**
A：合并时相等元素优先取左半部分（`a[i] <= a[j]`），左半元素原本就在右边相等元素之前，相对顺序得以保留。

**Q3：归并排序能原地做吗？**
A：数组的标准归并没有简单的 O(1) 额外空间实现；原地归并存在但复杂且常数大。链表归并可以利用指针做到 O(1) 额外空间。

**Q4：链表为什么适合归并排序？**
A：链表不支持随机访问，快排的分区不友好；归并只需要顺序遍历和改指针，合并两个有序链表是 O(1) 空间。

**Q5：怎么用归并求逆序对？**
A：合并时如果右半元素先被取出，说明它小于左半剩余的所有元素，逆序对增加 `mid - i + 1`。

**Q6：归并和快排怎么选？**
A：需要稳定或最坏 O(n log n) 用归并；追求原地、平均更快用快排。`std::sort` 通常是不稳定的 introsort，`std::stable_sort` 才保证稳定。

**Q7：自底向上的归并怎么写？**
A：从宽度 1 开始，每轮把相邻两个宽度为 `w` 的有序段合并，`w` 翻倍，直到覆盖整个数组；不需要递归栈。

## 易错点与加分点

- 合并时用 `<` 而不是 `<=`，破坏稳定性。
- 忘记处理剩余元素，或缓冲区下标错位。
- 以为归并是原地排序。
- 链表找中点时快慢指针初始化错误，导致死循环。
- 能说出「稳定性的来源是相等时取左」和「链表归并 O(1) 空间」。
