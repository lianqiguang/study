# 动态规划

> 一句话结论：DP = 状态定义 + 转移方程 + 初始化 + 遍历顺序；先把「`dp[i]` 表示什么」说清楚，再考虑滚动数组压缩空间。

## 为什么考 / 怎么考

DP 是中级面试的分水岭：套路都听过，能不能独立定义状态才是区分点。典型追问链：

1. 怎么定义状态？
2. 0/1 背包为什么一维要逆序？
3. LIS 的 O(n log n) 解法里 `tails` 是什么？
4. 编辑距离的三种操作对应哪些转移？
5. DP 和贪心怎么选？

## 解题五步

1. **定义状态**：`dp[i]` 或 `dp[i][j]` 表示什么；
2. **转移方程**：从哪些更小的状态推过来；
3. **初始化**：边界值，空串/容量 0/第 0 个元素；
4. **遍历顺序**：保证用到的状态已经算好；
5. **空间优化**：能否压成一维、能否用滚动数组。

状态定义决定了后面所有步骤。定义不清晰，转移一定写不对。

## 经典模型

### 1. 0/1 背包

每件物品只能选一次。一维写法必须**逆序**遍历容量：`dp[c]` 依赖上一轮的 `dp[c - w[i]]`，正序会让同一件物品被重复使用。

```cpp
#include <algorithm>
#include <cstddef>
#include <vector>

int knapsack01(const std::vector<int>& weight,
               const std::vector<int>& value,
               int capacity) {
    std::vector<int> dp(capacity + 1, 0);
    for (std::size_t i = 0; i < weight.size(); ++i) {
        for (int c = capacity; c >= weight[i]; --c) {   // 逆序
            dp[c] = std::max(dp[c], dp[c - weight[i]] + value[i]);
        }
    }
    return dp[capacity];
}
```

完全背包（物品无限）把容量循环改成**正序**即可。

### 2. 最长递增子序列（LIS）

O(n²) 的 `dp[i]` 表示以 `i` 结尾的 LIS 长度；O(n log n) 维护一个 `tails` 数组：

- `tails[k]` 表示长度为 `k + 1` 的递增子序列的最小结尾值；
- 新元素用 `lower_bound` 找到第一个 ≥ 它的位置替换；
- `tails` 的长度就是 LIS 长度，但 `tails` 本身不一定是某个合法子序列。

```cpp
#include <algorithm>
#include <vector>

int lengthOfLIS(const std::vector<int>& nums) {
    std::vector<int> tails;
    for (int x : nums) {
        auto it = std::lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return static_cast<int>(tails.size());
}
```

### 3. 最长公共子序列（LCS）

`dp[i][j]` 表示 `a` 的前 `i` 个字符与 `b` 的前 `j` 个字符的 LCS 长度：

- 字符相等：`dp[i][j] = dp[i-1][j-1] + 1`；
- 否则：`max(dp[i-1][j], dp[i][j-1])`。

```cpp
#include <algorithm>
#include <cstddef>
#include <string>
#include <vector>

int lcs(const std::string& a, const std::string& b) {
    std::vector<std::vector<int>> dp(
        a.size() + 1, std::vector<int>(b.size() + 1, 0));

    for (std::size_t i = 1; i <= a.size(); ++i) {
        for (std::size_t j = 1; j <= b.size(); ++j) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = std::max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    return dp[a.size()][b.size()];
}
```

### 4. 编辑距离

`dp[i][j]` 是把 `a` 的前 `i` 个字符变成 `b` 的前 `j` 个字符的最少操作数：

- 相等：不变；
- 否则：插入、删除、替换三种操作取最小，再加 1。

```cpp
#include <algorithm>
#include <cstddef>
#include <string>
#include <vector>

int editDistance(const std::string& a, const std::string& b) {
    std::vector<std::vector<int>> dp(
        a.size() + 1, std::vector<int>(b.size() + 1));

    for (std::size_t i = 0; i <= a.size(); ++i) dp[i][0] = static_cast<int>(i);
    for (std::size_t j = 0; j <= b.size(); ++j) dp[0][j] = static_cast<int>(j);

    for (std::size_t i = 1; i <= a.size(); ++i) {
        for (std::size_t j = 1; j <= b.size(); ++j) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + std::min({dp[i - 1][j],     // 删除
                                         dp[i][j - 1],     // 插入
                                         dp[i - 1][j - 1]}); // 替换
            }
        }
    }
    return dp[a.size()][b.size()];
}
```

### 5. 最大子数组和（Kadane）

`cur` 表示以当前元素结尾的最大和：`cur = max(x, cur + x)`；`best` 记录全局最大。

```cpp
#include <algorithm>
#include <cstddef>
#include <vector>

int maxSubArray(const std::vector<int>& nums) {
    int cur = nums[0];
    int best = nums[0];
    for (std::size_t i = 1; i < nums.size(); ++i) {
        cur = std::max(nums[i], cur + nums[i]);
        best = std::max(best, cur);
    }
    return best;
}
```

## 高频追问

**Q1：怎么定义 DP 状态？**
A：用一句话说清 `dp[...]` 表示「前 i 个元素/容量为 c/以 i 结尾」的什么值；状态要能覆盖所有转移，且无后效性。

**Q2：0/1 背包一维为什么逆序，完全背包为什么正序？**
A：逆序保证 `dp[c - w]` 还是上一轮（未选当前物品）的值；正序会让当前物品在同一轮被重复使用，正好对应完全背包。

**Q3：LIS 的 `tails` 是答案子序列吗？**
A：不是。`tails[k]` 只是长度为 k+1 的递增子序列的最小结尾值，用来加速替换；长度是答案，内容不一定是合法子序列。

**Q4：编辑距离的三种操作怎么对应转移？**
A：删除对应 `dp[i-1][j]`，插入对应 `dp[i][j-1]`，替换对应 `dp[i-1][j-1]`；取三者最小值加一。

**Q5：DP 和贪心怎么选？**
A：贪心要求每步局部最优能推出全局最优（需要证明）；DP 枚举所有子问题，适用范围更广但状态/空间更大。

**Q6：DP 的空间怎么压缩？**
A：如果 `dp[i]` 只依赖 `dp[i-1]`，可以滚动数组；0/1 背包可以压成一维但要注意遍历方向；必要时只保留上一行。

**Q7：DP 的时间复杂度怎么估？**
A：状态数 × 每个状态的转移数。例如 LCS 是 O(nm) 个状态、O(1) 转移，总 O(nm)。

## 易错点与加分点

- 状态定义含糊，转移写到一半发现信息不够。
- 0/1 背包一维正序，物品被重复使用。
- 初始化漏掉空串/容量 0 的边界。
- LIS 把 `tails` 当成答案子序列。
- 编辑距离三个转移方向写反。
- 能说出「状态无后效性」和「滚动数组的依赖方向」，是加分项。
