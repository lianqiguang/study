# 图算法基础

> 一句话结论：图题先选表示（邻接表 O(V+E) / 邻接矩阵 O(V²)）；BFS 求无权最短路，DFS 做连通与遍历，Kahn 做拓扑排序，Dijkstra 求非负权最短路，并查集维护连通性。

## 为什么考 / 怎么考

图算法考的是「选对工具」：什么时候 BFS、什么时候 Dijkstra、什么时候并查集。典型追问链：

1. 邻接表和邻接矩阵怎么选？
2. BFS 为什么能求无权最短路？
3. 拓扑排序怎么检测环？
4. Dijkstra 为什么不能处理负权？
5. 并查集的复杂度是多少？

## 表示

- **邻接表**：`std::vector<std::vector<int>>`，空间 O(V+E)，遍历邻居快，适合稀疏图；
- **邻接矩阵**：`vector<vector<int>>`，空间 O(V²)，O(1) 判断两点是否有边，适合稠密图；
- **边列表**：`vector<tuple<u,v,w>>`，适合 Kruskal、Bellman-Ford。

## BFS：无权最短路

从起点出发按层扩展，第一次到达某点时的层数就是最短距离（边权都为 1）。

```cpp
#include <queue>
#include <vector>

int bfsShortest(const std::vector<std::vector<int>>& g, int s, int t) {
    std::vector<int> dist(g.size(), -1);
    std::queue<int> q;

    dist[s] = 0;
    q.push(s);

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist[t];
}
```

## DFS：连通性与遍历

递归实现最直观；图很大时改用显式栈，避免递归过深。

```cpp
#include <vector>

void dfs(const std::vector<std::vector<int>>& g,
         int u,
         std::vector<bool>& visited) {
    visited[u] = true;
    for (int v : g[u]) {
        if (!visited[v]) dfs(g, v, visited);
    }
}
```

## 拓扑排序（Kahn）

统计入度，入度为 0 的节点入队；每次取出一个节点，把它的邻居入度减一，减到 0 就入队。

- 输出顺序是一个合法拓扑序；
- 如果最终节点数小于 V，说明有环。

```cpp
#include <cstddef>
#include <queue>
#include <vector>

std::vector<int> topoSort(const std::vector<std::vector<int>>& g) {
    std::vector<int> indegree(g.size(), 0);
    for (const auto& edges : g) {
        for (int v : edges) ++indegree[v];
    }

    std::queue<int> q;
    for (std::size_t i = 0; i < g.size(); ++i) {
        if (indegree[i] == 0) q.push(static_cast<int>(i));
    }

    std::vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : g[u]) {
            if (--indegree[v] == 0) q.push(v);
        }
    }
    return order;   // order.size() < g.size() 表示有环
}
```

## Dijkstra：非负权最短路

用优先队列（小顶堆）每次取出当前距离最小的节点，松弛它的邻居。

```cpp
#include <functional>
#include <queue>
#include <utility>
#include <vector>

using Edge = std::pair<int, int>;   // (weight, to)
using DistNode = std::pair<int, int>; // (dist, node)

std::vector<int> dijkstra(const std::vector<std::vector<Edge>>& g, int s) {
    const int INF = 1000000000;
    std::vector<int> dist(g.size(), INF);

    std::priority_queue<DistNode,
                        std::vector<DistNode>,
                        std::greater<DistNode>> pq;

    dist[s] = 0;
    pq.push({0, s});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d != dist[u]) continue;   // 过期条目

        for (auto [w, v] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

复杂度 O((V+E) log V)。**不能处理负权边**：Dijkstra 假设「已确定的最短距离不会再变小」，负权会破坏这个前提。负权用 Bellman-Ford（O(VE)，可检测负环）。

## 并查集

维护不相交集合，支持合并与查询连通性：

- `find`：路径压缩；
- `unite`：按大小（或秩）合并；
- 均摊复杂度接近 O(1)（反阿克曼函数 α(n)）。

```cpp
#include <numeric>
#include <utility>
#include <vector>

class DSU {
public:
    explicit DSU(int n) : parent_(n), size_(n, 1) {
        std::iota(parent_.begin(), parent_.end(), 0);
    }

    int find(int x) {
        return parent_[x] == x ? x : parent_[x] = find(parent_[x]);
    }

    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return false;

        if (size_[a] < size_[b]) std::swap(a, b);
        parent_[b] = a;
        size_[a] += size_[b];
        return true;
    }

private:
    std::vector<int> parent_;
    std::vector<int> size_;
};
```

## 高频追问

**Q1：邻接表和邻接矩阵怎么选？**
A：稀疏图用邻接表（空间 O(V+E)，遍历邻居快）；稠密图或需要 O(1) 判断两点相邻时用矩阵（空间 O(V²)）。

**Q2：BFS 为什么能求无权最短路？**
A：BFS 按距离逐层扩展，第一次访问到某点时经过的边数最少；边权都为 1 时，层数就是最短距离。

**Q3：拓扑排序怎么检测环？**
A：Kahn 算法结束时如果输出节点数小于 V，说明剩下的节点互相依赖形成环；DFS 也可以用「三色标记」检测回边。

**Q4：Dijkstra 为什么不能处理负权？**
A：它假设出堆的节点距离已经最终确定；负权边可能让已确定的节点变得更短，破坏贪心前提。

**Q5：并查集的复杂度？**
A：路径压缩 + 按秩/按大小合并，均摊 O(α(n))，近似常数；单次最坏仍可能较高，但摊还后很快。

**Q6：Dijkstra 和 Bellman-Ford 怎么选？**
A：非负权用 Dijkstra，O((V+E) log V)；有负权用 Bellman-Ford，O(VE)，还能检测负环；多源最短路用 Floyd，O(V³)。

**Q7：DFS 和 BFS 怎么选？**
A：求最短步数/层序用 BFS；求连通分量、拓扑、回溯、路径存在性用 DFS。两者时间都是 O(V+E)。

## 易错点与加分点

- 邻接矩阵用在稀疏图上，空间爆掉。
- BFS 忘记 `visited` 或入队时就标记，导致重复入队。
- 拓扑排序只检查入度，忘记最后判断节点数。
- Dijkstra 用负权，或忘记跳过过期堆条目。
- 并查集只写 `find` 不压缩，复杂度退化。
- 能说出「Dijkstra 的贪心前提」和「并查集的摊还复杂度」，是加分项。
