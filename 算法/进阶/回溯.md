# 回溯

> 一句话结论：回溯 = 做选择 + 递归 + 撤销选择；它在决策树上做 DFS，用剪枝控制规模。子集/组合靠 `start` 去重，排列靠 `used` 标记，棋盘类靠行列/对角线约束。

## 为什么考 / 怎么考

回溯是「排列组合 + 棋盘搜索」的通用框架，面试官主要看你能不能写对撤销和去重。典型追问链：

1. 回溯的模板是什么？
2. 子集和组合的 `start` 参数有什么区别？
3. 排列怎么处理重复元素？
4. N 皇后怎么表示两条对角线？
5. 回溯的时间复杂度怎么估？

## 模板

```text
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        记录结果;
        return;
    }
    for (选择 : 选择列表) {
        if (剪枝) continue;
        做选择;
        backtrack(路径, 新的选择列表);
        撤销选择;
    }
}
```

关键点：

- 「做选择」和「撤销选择」必须成对出现；
- 子集/组合用 `start` 控制只能选后面的元素，避免重复；
- 排列用 `used` 标记已选元素；
- 去重的前提通常是先排序，再在同一层跳过相同元素。

## 代码示例

子集：

```cpp
#include <vector>

void dfs(const std::vector<int>& nums,
         int start,
         std::vector<int>& path,
         std::vector<std::vector<int>>& out) {
    out.push_back(path);

    for (int i = start; i < static_cast<int>(nums.size()); ++i) {
        path.push_back(nums[i]);
        dfs(nums, i + 1, path, out);
        path.pop_back();
    }
}

std::vector<std::vector<int>> subsets(const std::vector<int>& nums) {
    std::vector<std::vector<int>> out;
    std::vector<int> path;
    dfs(nums, 0, path, out);
    return out;
}
```

全排列：

```cpp
#include <vector>

void dfs(const std::vector<int>& nums,
         std::vector<bool>& used,
         std::vector<int>& path,
         std::vector<std::vector<int>>& out) {
    if (path.size() == nums.size()) {
        out.push_back(path);
        return;
    }

    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        if (used[i]) continue;

        used[i] = true;
        path.push_back(nums[i]);
        dfs(nums, used, path, out);
        path.pop_back();
        used[i] = false;
    }
}

std::vector<std::vector<int>> permute(const std::vector<int>& nums) {
    std::vector<std::vector<int>> out;
    std::vector<int> path;
    std::vector<bool> used(nums.size(), false);
    dfs(nums, used, path, out);
    return out;
}
```

组合（从 1..n 中选 k 个）：

```cpp
#include <vector>

void dfs(int n,
         int k,
         int start,
         std::vector<int>& path,
         std::vector<std::vector<int>>& out) {
    if (static_cast<int>(path.size()) == k) {
        out.push_back(path);
        return;
    }

    for (int i = start; i <= n; ++i) {
        path.push_back(i);
        dfs(n, k, i + 1, path, out);
        path.pop_back();
    }
}
```

含重复元素的子集去重（先排序）：

```cpp
#include <vector>

void dfs(const std::vector<int>& nums,
         int start,
         std::vector<int>& path,
         std::vector<std::vector<int>>& out) {
    out.push_back(path);

    for (int i = start; i < static_cast<int>(nums.size()); ++i) {
        if (i > start && nums[i] == nums[i - 1]) continue;   // 同层跳过重复
        path.push_back(nums[i]);
        dfs(nums, i + 1, path, out);
        path.pop_back();
    }
}
```

N 皇后：

```cpp
#include <string>
#include <vector>

void dfs(int row,
         int n,
         std::vector<bool>& col,
         std::vector<bool>& diag1,
         std::vector<bool>& diag2,
         std::vector<std::string>& board,
         std::vector<std::vector<std::string>>& out) {
    if (row == n) {
        out.push_back(board);
        return;
    }

    for (int c = 0; c < n; ++c) {
        int d1 = row + c;
        int d2 = row - c + n - 1;   // 平移到非负下标

        if (col[c] || diag1[d1] || diag2[d2]) continue;

        col[c] = diag1[d1] = diag2[d2] = true;
        board[row][c] = 'Q';

        dfs(row + 1, n, col, diag1, diag2, board, out);

        board[row][c] = '.';
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}

std::vector<std::vector<std::string>> solveNQueens(int n) {
    std::vector<std::vector<std::string>> out;
    std::vector<std::string> board(n, std::string(n, '.'));
    std::vector<bool> col(n);
    std::vector<bool> diag1(2 * n - 1);
    std::vector<bool> diag2(2 * n - 1);

    dfs(0, n, col, diag1, diag2, board, out);
    return out;
}
```

## 高频追问

**Q1：回溯和 DFS 是什么关系？**
A：回溯是在决策树上做 DFS：每层做一个选择，递归进入下一层，返回时撤销。DFS 是遍历方式，回溯强调「选择-撤销」的搜索框架。

**Q2：子集和组合的 `start` 参数有什么区别？**
A：子集每次递归从 `i + 1` 继续，记录所有节点；固定长度组合在 `path.size() == k` 时收集，同样用 `start` 防止重复。排列不用 `start`，而用 `used` 标记。

**Q3：排列怎么处理重复元素？**
A：先排序，再用 `used`；当 `nums[i] == nums[i-1]` 且 `used[i-1] == false` 时跳过，保证相同元素按固定顺序使用。

**Q4：N 皇后的两条对角线怎么表示？**
A：主对角线 `row - col` 为常数，副对角线 `row + col` 为常数；`row - col` 可能为负，平移到 `row - col + n - 1` 作为下标。

**Q5：回溯的时间复杂度怎么估？**
A：看决策树节点数：子集 O(2^n)，排列 O(n!)，组合 O(C(n,k))；N 皇后剪枝后远小于 n!，但最坏仍是指数级。

**Q6：剪枝怎么做？**
A：提前判断当前路径是否可能产生合法解：组合里剩余元素不够、N 皇后对角线冲突、目标和已超过等，尽早 `continue`。

**Q7：回溯的空间复杂度？**
A：递归深度 + 路径/标记数组，通常是 O(n) 到 O(n²)（N 皇后棋盘），不含结果集。

## 易错点与加分点

- 忘记撤销选择，导致后续分支被污染。
- 子集/组合不用 `start`，产生重复组合。
- 去重不排序，或跳过条件写成 `nums[i] == nums[i-1]`（会跳过合法分支）。
- N 皇后对角线下标为负，越界。
- 把结果存成引用，递归返回后被修改。
- 能说出「同一层去重」与「同一路径去重」的区别，是加分项。
