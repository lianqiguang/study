# 滑动窗口与双指针

> 一句话结论：滑动窗口处理「连续子数组/子串」且条件具有单调性的问题：右指针扩张，左指针的收缩时机取决于求最长还是最短——最长在窗口不合法时收缩，最短在窗口合法时收缩以找更短解；双指针则利用有序性或两端性质，把 O(n²) 降到 O(n)。

## 为什么考 / 怎么考

这两类技巧是「把暴力 O(n²) 优化到 O(n)」的标准答案，面试官主要看你能不能写对窗口边界和收缩时机。典型追问链：

1. 什么时候能用滑动窗口？
2. 最长和最短窗口的更新时机有什么区别？
3. 双指针为什么能对有序数组求和？
4. 盛水容器为什么移动较矮的一侧？
5. 定长窗口怎么维护最大值？

## 滑动窗口模板

最长窗口和最短窗口的收缩条件不同，要分开记。

**最长窗口**（求满足条件的最长区间）：

```text
l = 0
for r in 0..n-1:
    把 a[r] 加入窗口
    while 窗口不满足条件:
        把 a[l] 移出窗口
        ++l
    更新答案（当前窗口合法）
```

**最短窗口**（求满足条件的最短区间）：

```text
l = 0
for r in 0..n-1:
    把 a[r] 加入窗口
    while 窗口满足条件:
        更新答案（当前窗口合法）
        把 a[l] 移出窗口
        ++l
```

- 每轮开始时窗口是 `[l, r)`；加入 `a[r]` 后是 `[l, r+1)`，长度为 `r - l + 1`；
- 条件必须具有单调性：右指针扩张只会让条件更难满足（或更容易），左指针收缩能恢复。

## 代码示例

无重复字符的最长子串：

```cpp
#include <algorithm>
#include <array>
#include <string>

int lengthOfLongestSubstring(const std::string& s) {
    std::array<int, 256> last;
    last.fill(-1);

    int best = 0;
    int l = 0;
    for (int r = 0; r < static_cast<int>(s.size()); ++r) {
        unsigned char c = static_cast<unsigned char>(s[r]);
        if (last[c] >= l) {
            l = last[c] + 1;   // 直接跳到重复字符的下一位
        }
        last[c] = r;
        best = std::max(best, r - l + 1);
    }
    return best;
}
```

最小覆盖子串：

```cpp
#include <array>
#include <climits>
#include <string>

std::string minWindow(const std::string& s, const std::string& t) {
    std::array<int, 256> need{};
    std::array<int, 256> have{};
    int required = 0;

    for (unsigned char c : t) {
        if (need[c]++ == 0) ++required;
    }

    int formed = 0;
    int l = 0;
    int bestLen = INT_MAX;
    int bestL = 0;

    for (int r = 0; r < static_cast<int>(s.size()); ++r) {
        unsigned char c = static_cast<unsigned char>(s[r]);
        if (++have[c] == need[c]) ++formed;

        while (formed == required) {          // 窗口已覆盖 t
            if (r - l + 1 < bestLen) {
                bestLen = r - l + 1;
                bestL = l;
            }
            unsigned char d = static_cast<unsigned char>(s[l++]);
            if (have[d]-- == need[d]) --formed;
        }
    }
    return bestLen == INT_MAX ? "" : s.substr(bestL, bestLen);
}
```

有序数组两数之和（返回是否存在）：

```cpp
#include <vector>

bool hasPair(const std::vector<int>& a, int target) {
    int l = 0;
    int r = static_cast<int>(a.size()) - 1;

    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) return true;
        if (sum < target) ++l;
        else --r;
    }
    return false;
}
```

盛水容器：

```cpp
#include <algorithm>
#include <vector>

int maxArea(const std::vector<int>& height) {
    int l = 0;
    int r = static_cast<int>(height.size()) - 1;
    int best = 0;

    while (l < r) {
        best = std::max(best, std::min(height[l], height[r]) * (r - l));
        if (height[l] < height[r]) ++l;   // 移动较矮的一侧
        else --r;
    }
    return best;
}
```

有序数组去重（快慢指针）：

```cpp
#include <vector>

int removeDuplicates(std::vector<int>& a) {
    if (a.empty()) return 0;

    int slow = 0;
    for (int fast = 1; fast < static_cast<int>(a.size()); ++fast) {
        if (a[fast] != a[slow]) {
            a[++slow] = a[fast];
        }
    }
    return slow + 1;
}
```

### 定长窗口

窗口大小固定为 k 时，右指针进一个、左指针出一个，维护窗口内的和/计数；如果要求窗口最大值，用单调队列（`std::deque`）维护递减序列，均摊 O(1)。

## 高频追问

**Q1：什么时候能用滑动窗口？**
A：问题针对连续区间，且区间扩张/收缩时条件单调变化（例如「不同字符数」「覆盖计数」）；如果条件不具单调性，窗口收缩无法恢复，就不适用。

**Q2：最长窗口和最短窗口的更新时机有什么区别？**
A：最长窗口在窗口合法时更新答案；最短窗口在窗口合法时先更新答案，再收缩左边界，直到不合法。

**Q3：最小覆盖子串里 `formed == required` 表示什么？**
A：表示窗口内每种目标字符的数量都达到了需求；此时窗口是一个可行解，可以尝试收缩左边界找更短的。

**Q4：盛水容器为什么移动较矮的一侧？**
A：面积由较矮的一侧决定；移动较高的一侧不会增加高度，宽度还会减小，不可能得到更大面积，所以只能移动较矮的一侧。

**Q5：定长窗口的最大值怎么维护？**
A：用单调递减队列：新元素入队前弹出比它小的尾部元素，超出窗口的左端从队首弹出；队首就是当前窗口最大值，均摊 O(n)。

**Q6：双指针为什么能把两数之和降到 O(n)？**
A：数组有序时，和小于目标就移动左指针增大和，和大于目标就移动右指针减小和，每次排除一个不可能的组合。

**Q7：滑动窗口的时间复杂度怎么算？**
A：左右指针各自最多移动 n 次，每个元素最多进出窗口一次，总 O(n)（忽略哈希/计数数组的常数操作）。

## 易错点与加分点

- 窗口边界用闭区间，收缩时忘了同步长度。
- 最短窗口先收缩再更新答案，漏掉更短的解。
- `have[d]--` 放在判断前，计数逻辑错乱。
- 盛水容器移动较高一侧，得到错误结果。
- 定长窗口用堆维护最大值，复杂度退化为 O(n log k)。
- 能说出「条件单调性」是滑动窗口成立的前提，是加分项。
