# C++11–17 高频特性

> 一句话结论：C++11 引入移动语义、lambda、auto/decltype 和并发库，C++14 做小幅增强（`make_unique`、泛型 lambda、放宽 constexpr），C++17 带来结构化绑定、`if constexpr`、折叠表达式和一批标准库组件（`optional/variant/any/string_view`）。

## 为什么考 / 怎么考

中级岗位要求「熟悉现代 C++」，面试官会挑几个高频特性验证你是否真的用过，而不是只会背列表。典型追问链：

1. `auto` 和 `decltype` 有什么区别？
2. lambda 的捕获有哪些坑？
3. `std::function` 有什么开销？
4. `std::async` 和 `std::thread` 怎么选？
5. C++17 你常用哪些特性？

## 原理

### 1. auto / decltype / decltype(auto)

- `auto` 按值推导，**丢弃引用和顶层 const**；
- `decltype(expr)` 保留表达式的引用和 const 属性；
- `decltype(auto)`（C++14）按 `decltype` 规则推导返回类型，常用于完美转发返回。

```cpp
#include <iostream>

int main() {
    int x = 1;
    const int& rx = x;

    auto a = rx;         // int：丢弃引用和顶层 const
    decltype(rx) b = x;  // const int&：保留引用和 const

    std::cout << a << ' ' << b << '\n';
}
```

### 2. lambda 表达式

- 捕获列表：`[=]` 按值、`[&]` 按引用、`[x]` / `[&x]` 指定变量、`[this]` 捕获 this；
- `mutable` 允许修改按值捕获的副本；
- C++14 支持初始化捕获 `[x = std::move(v)]` 和泛型 lambda `[](auto a, auto b){}`；
- 按引用捕获要注意生命周期：lambda 存活期间被捕获对象必须仍然有效。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v{3, 1, 2};
    int factor = 2;

    auto scaled = [factor](int x) { return x * factor; };  // 按值捕获
    std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });

    auto add = [](auto a, auto b) { return a + b; };       // C++14 泛型 lambda
    std::cout << scaled(3) << ' ' << add(1, 2.5) << '\n';
}
```

### 3. constexpr

- C++11：`constexpr` 函数限制为单条 return 等严格形式；
- C++14：放宽为普通函数体（循环、局部变量）；
- C++17：`if constexpr` 在编译期丢弃分支，`constexpr` lambda 等进一步增强。

`const` 只表示只读，`constexpr` 要求可在编译期求值。细节见 [const / static / volatile](../基础/const-static-volatile.md)。

### 4. C++14 的实用增强

- `std::make_unique<T>(args...)`：补上 `make_shared` 对应的工厂；
- 泛型 lambda；
- 初始化捕获；
- 变量模板（`template <typename T> constexpr T pi = T(3.14159);`）；
- 放宽的 `constexpr`。

### 5. C++17 语言特性

- **结构化绑定**：`auto [a, b] = pair;`。注意 `auto` 版本会复制，需要避免复制时用 `auto&` / `const auto&`。
- **`if constexpr`**：条件必须是编译期常量，未选中的分支在编译期丢弃，可用于替代 SFINAE 做类型分派。
- **折叠表达式**：`(xs + ...)` 展开参数包。
- **CTAD**（类模板实参推导）：`std::vector v{1, 2, 3};`。
- **`inline` 变量**：头文件里定义全局/静态成员变量不再需要额外的 .cpp。
- **嵌套命名空间**：`namespace a::b {}`。
- **属性**：`[[nodiscard]]`、`[[maybe_unused]]`、`[[fallthrough]]`。

```cpp
#include <iostream>
#include <tuple>
#include <type_traits>

template <typename T>
const char* describe(T) {
    if constexpr (std::is_integral_v<T>) {
        return "integer";
    } else {
        return "other";
    }
}

int main() {
    auto [a, b] = std::make_pair(1, 2.5);   // 结构化绑定（按值复制）
    std::cout << a << ' ' << b << ' ' << describe(1) << '\n';
}
```

```cpp
#include <iostream>
#include <vector>

template <typename... Ts>
auto sum(Ts... xs) {
    return (xs + ...);   // C++17 折叠表达式
}

struct Counter {
    inline static int total = 0;   // C++17 inline 变量
};

int main() {
    std::vector v{1, 2, 3};   // C++17 CTAD
    Counter::total += static_cast<int>(v.size());
    std::cout << sum(1, 2, 3) << ' ' << Counter::total << '\n';
}
```

### 6. C++17 标准库组件

- `std::optional<T>`：可能没有值的对象，替代「用特殊值/空指针表示缺失」；
- `std::variant<Ts...>`：类型安全的联合体，用 `std::get` / `std::visit` 访问；
- `std::any`：可存放任意类型的值，运行时类型擦除；
- `std::string_view`：非拥有字符串视图，避免拷贝，但不保证以 `\0` 结尾，源字符串销毁后会悬垂；
- `std::filesystem`：路径、目录遍历、文件操作（需要链接 `stdc++fs` 的旧编译器）。

```cpp
#include <iostream>
#include <optional>
#include <string>
#include <string_view>
#include <variant>

int main() {
    std::optional<int> o = 42;
    std::variant<int, std::string> v = std::string("hi");
    std::string_view sv = "hello";

    std::cout << *o << ' ' << std::get<std::string>(v) << ' ' << sv << '\n';
}
```

### 7. std::function / std::bind / std::async / std::future

- `std::function<Sig>`：类型擦除的可调用对象包装器，可存函数指针、lambda、成员函数绑定结果；有类型擦除和可能的堆分配开销。
- `std::bind`：绑定部分参数，C++11 起可用；现代代码更推荐直接用 lambda。
- `std::async`：启动异步任务，返回 `std::future`；不指定策略时，实现可以选择立即执行或延迟执行（deferred）。
- `std::future::get()`：等待并取结果；只能 `get` 一次。

```cpp
#include <functional>
#include <future>
#include <iostream>

int add(int a, int b) { return a + b; }

int main() {
    std::function<int(int)> f = std::bind(add, 10, std::placeholders::_1);
    auto fut = std::async(std::launch::async, add, 1, 2);

    std::cout << f(5) << ' ' << fut.get() << '\n'; // 15 3
}
```

### 8. thread_local

`thread_local` 变量每个线程一份，生命周期与线程绑定，适合线程本地缓存、错误码等：

```cpp
#include <iostream>

thread_local int local = 0;

void bump() {
    ++local;
    std::cout << local << '\n';   // 每个线程从 1 开始
}
```

### 9. C++20 简述

- concepts / requires：约束模板参数，错误信息更清晰；
- ranges：范围库与管道语法；
- coroutines：协程；
- 三路比较 `<=>`；
- `std::span`、`std::jthread`、`std::atomic<std::shared_ptr<T>>`。

本轮不展开，面试中能说出用途即可。

## 高频追问

**Q1：`auto` 和 `decltype` 有什么区别？**
A：`auto` 按值推导，丢弃引用和顶层 const；`decltype` 保留表达式的引用和 const 属性。需要保留引用时用 `decltype` 或 `decltype(auto)`。

**Q2：lambda 捕获有哪些坑？**
A：按值捕获在创建时复制，之后修改副本需要 `mutable`；按引用捕获可能悬垂；`[this]` 捕获的是指针，对象销毁后调用同样悬垂。

**Q3：`std::function` 有什么开销？**
A：类型擦除（虚调用）和可能的堆分配；小对象通常有 SBO 优化，但高频调用路径上直接传 lambda 模板参数更轻。

**Q4：`std::async` 和 `std::thread` 怎么选？**
A：`std::async` 返回 `future`，能取返回值/异常，生命周期管理更简单；`std::thread` 更底层，需要手动 `join/detach`。注意 `std::async` 默认策略可能延迟执行，需要立即执行时显式传 `std::launch::async`。

**Q5：`std::optional` 和指针怎么选？**
A：表示「可能没有值」且不需要多态/共享所有权时用 `optional`，值语义、无堆分配；需要多态或可能为空的对象指针时用指针/智能指针。

**Q6：`if constexpr` 和普通 `if` 有什么区别？**
A：`if constexpr` 的条件必须是编译期常量，未选中的分支在编译期丢弃，可以写只在某些类型下合法的代码；普通 `if` 两个分支都必须编译。

**Q7：C++17 你常用哪些特性？**
A：结构化绑定、`if constexpr`、`optional/variant/string_view`、CTAD、`inline` 变量、折叠表达式、`filesystem`。

**Q8：`std::string_view` 有什么风险？**
A：它不拥有数据，源字符串销毁或修改后视图会悬垂；不能假设以 `\0` 结尾，传给需要 C 字符串的接口要用 `std::string`。

## 易错点与加分点

- 以为 `auto` 会保留引用或 const（实际会丢弃）。
- 用 `auto` 结构化绑定产生不必要的拷贝。
- 用 `std::bind` 写复杂逻辑，可读性不如 lambda。
- `std::async` 不指定策略，误以为一定在新线程执行。
- `string_view` 指向临时字符串，导致悬垂。
- 能说出 `std::function` 的类型擦除和 SBO，以及它不适合极热路径。
